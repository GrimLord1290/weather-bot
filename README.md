# Telegram-бот «Погода» на Python

Бот спрашивает город и отправляет текущую погоду через OpenWeatherMap API.

## Что делает
- Команда `/start` — приветствие.
- Пользователь пишет город.
- Бот отправляет: температуру, ощущаемую температуру, описание, влажность.

## Стек
- Python
- aiogram (Telegram Bot API)
- requests (OpenWeatherMap API)

## Как запустить
1. Установи библиотеки:
   `pip install aiogram requests`
2. Получи токен бота у @BotFather.
3. Получи API-ключ на openweathermap.org.
4. Вставь токен и ключ в `weather_bot.py`.
5. Запусти:
   `python weather_bot.py`
